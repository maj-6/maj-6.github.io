02 · Reproducible build

From immutable source to page-addressable layers

  1. Fix the source.Snapshot the selected catalogue rows and record the full catalogue checksum, stable PDF URL, byte count, page count, and PDF SHA-256 before processing.
  2. OCR every page.Call Mistral OCR 4 in resumable 50-page ranges, retaining each raw response, paragraph box, reading order, source type, and page-level confidence score.
  3. Normalize geometry.Convert page coordinates to a 0–1 grid and assign conservative, geometry-informed roles. Model labels remain styling hints.
  4. Keep two texts.Store untouched diplomatic OCR beside modern English keyed to the same stable region IDs. Give the translator one physical page of context, then reject missing, shifted, stale, or structurally inconsistent results rather than redistributing prose after the fact.
  5. Preserve original marks.Erase boxed source text from a scan-derived layer and make only paper-like pixels transparent. Woodcuts and ornaments are never regenerated.
  6. Match each leaf.Preserve each page’s sampled paper tone and use its sampled ink when readable; if scan noise makes the two colors too similar, shift only the facsimile text toward black or white until it reaches 4.5:1 contrast. Locally available book serifs are fitted within the recovered grid. This interprets hierarchy and density rather than claiming an exact type reconstruction.
  7. Publish for motion.Encode page scans and thumbnails as WebP, fetch only the current page, prefetch adjacent pages, and virtualize the filmstrip.

The build pins mistral-ocr-4-0 and mistral-large-2512; credentials are environment-only. Raw OCR, rejected translation responses, normalized accepted caches, and prompt/input hashes remain distinct so reruns are auditable. Duplicate JSON keys are rejected in both stored records and model-returned region maps.

03 · Quality assessment

Review what the system can—and cannot—prove

Every page, automatically

The build checks source bytes/hash/page count, page completeness, dimensions, unique region IDs, reading order, in-bounds geometry, text-layer coverage, asset headers, sampled colors, and likely illustration misses. A release fingerprint binds the reviewed config, annotations, normalized pages, scans, thumbnails, and art bytes.

Fifteen fixed visual samples

Five pages per book cover front matter, ordinary text, mixed layouts, full plates, colored woodcuts, decorated initials, indices, and late-book pages. The page set is fixed in configuration.

Observed strengths

Paragraph geometry and reading order were consistently useful. Roman Latin was the cleanest sample; the German Fraktur and English blackletter showed more historical-letter confusions.

Observed failures

A preliminary page-image probe missed Fuchs’s full-page plant on page 236, although the final document-range run boxed it correctly—evidence that illustration labels can vary by extraction mode. OCR also hallucinated content on blank or bleed-through leaves. Those reviewed page and region outputs are explicitly suppressed while every raw response remains retained. Early multi-page and proportional-reflow translation trials borrowed or shifted text. The production contract instead sends exactly one physical page at a time and maps every result directly back to its stable source-region ID; rejected trials remain outside the active cache.

No false precision

Model confidence is diagnostic, not accuracy. The PDFs’ hidden text layers are compared only as a disagreement baseline—not as ground truth. Without manually transcribed and boxed ground truth, this edition does not claim character error rate, word error rate, or layout IoU. Machine-assisted text remains unverified; cite the scan for scholarship. The remedies are presented as historical sources, not medical advice.

04 · Delivery & provenance

A small application, a private origin, and a clear chain back

GitHub Pages
reader + catalogue ↔ CloudFront
HTTPS + edge cache ↔ Private S3
versioned assets

All public book assets use an immutable version prefix. The S3 bucket blocks public access and grants read permission only to its CloudFront distribution; browser CORS is restricted to this site. Each manifest links back to the World Herb Library record, source PDF, source checksum and byte count, an independent bibliographic record, and exact processing models. The historical works are centuries old, but reuse statements for a particular institutional scan may be separate; provenance links are retained so downstream publishers can verify the applicable source terms.
